# TEMIN HUB v4.2 PWA

Pakej ini disediakan untuk GitHub Pages.

## Fail yang perlu dimuat naik

Muat naik semua kandungan folder ini ke root repositori `teminsmarthub`:

- `index.html`
- `manifest.json`
- `sw.js`
- `offline.html`
- folder `icons`

Kekalkan juga fail sedia ada `logo-sk-temin.png` di root repositori kerana `index.html` menggunakannya.

## Selepas dimuat naik

1. Tunggu GitHub Pages selesai menerbitkan perubahan.
2. Buka laman menggunakan Chrome pada Android atau Safari pada iPhone.
3. Tekan butang **Install App**.
4. Jika versi lama masih dipaparkan, tutup tab, buka semula dan muat semula halaman.

> PWA hanya berfungsi melalui HTTPS. GitHub Pages menyediakan HTTPS secara automatik.
